### S02 トイレ・シャワーのドラムピッカー

2026-10-13に提供された操作動画をUIの参照とする。動画ではトイレとシャワーに縦方向のホイールが1つずつあり、中央の選択値を大きな濃緑色の文字で示し、前後の候補を上下に薄く表示する。各カードにはグループ名、最大箇所数、「上下にスワイプして箇所数を変更」の案内がある。

- トイレは`0箇所・1箇所・2箇所`、シャワーは`0箇所・1箇所・2箇所・3箇所`を、それぞれ独立して選ぶ。数値は個別の場所を指さない。
- ホイール上を上下にスワイプすると候補が縦に動き、操作を終えた時点で最も近い有効な整数値を中央に揃える。中央の値を選択中の対象数として表示・保存し、上下の候補は選択状態として扱わない。動画で示された中央と前後の候補の視覚的な区別を維持する。
- 上限・下限を越えて循環させない。トイレとシャワーの操作は互いの値を変えない。戻る・再表示時は保存済みの対象数を中央に復元する。新規作業の初期値は動画だけでは確定できないため、別途決める。
- 値を変更したら作業の`targetCount`を更新する。変更前の進捗が新しい対象数に適合しない場合は再確認を促し、現行の実施数が対象数を超える値は保存しない。対象数0のグループはチェック一覧、報告可能判定、報告、履歴の現行対象から外す。
- スワイプを使えない場合にも値を選べる操作方法と、読み上げ時にグループ名・現在値・選択可能範囲が分かる表現を設ける。見た目だけで値を判断させない。

## 主な遷移と日付変更

`S00 → S01 → S02 → S03 ↔ S04 → S05 ↔ D00 → D01 → S06`。S03からS02へ戻って対象を変更できる。S01またはS03からS07、S03またはS07からS10、S07からS08→S09へ進む。

日本時間で日付が変わると当日の画面は新規作業に切り替え、前日の作業は削除せずアーカイブへ移す。アプリを開いたまま日付をまたぐ場合、閉じて翌日開く場合、オフラインで未同期の入力が残る場合を検証する。前日の未同期入力は保持し、日付を新しい作業へ書き換えない。過去日の報告では作業日を示して再確認する。

## マスタ変更の保留事項

マスタ変更の承認者・人数・本人確認・承認取得／記録方法・タイミングは2026-10-13から保留する。従来の2名の氏名入力・担当職員による自己申告は旧案であり、S10の確定した操作ではない。条件が決まるまで申請確定・Chatwork通知を行わない。編集方法と権限、確認者、確認記録、適用日の起点も決定後に画面、API、状態遷移、受け入れテストを同時に更新する。過去記録を参照するマスタ版は維持する。
